## 🌟 About ONewPipe

ONewPipe is a privacy-focused, lightweight, and responsive frontend for YouTube, SoundCloud, and Bandcamp. Built on top of the rock-solid NewPipe core, this fork takes user experience to the next level by:
- 🎨 **Adapting Dynamically**: The interface colors match the service you are using (YouTube Red, SoundCloud Orange, Bandcamp Blue).
- 💻 **Being Cross-Platform**: ONewPipe isn't just an Android app. It offers native desktop applications for Windows and Linux through Compose Multiplatform.

## ✨ Features
- **All the features of NewPipe**: No ads, background playback, downloads, subscriptions without an account.
- **Dynamic Theming**: True visual identities for YouTube, SoundCloud, and Bandcamp.
- **Desktop Support**: Available natively on Windows and Linux!
